# Repository Rules

These rules are non-negotiable and apply to the entire repository.

## Accuracy and sources

- Never invent professional information.
- Never invent employers, clients, projects, dates, awards, roles, metrics, or software proficiency.
- Repository files are the primary source of truth.
- Carrd is a migration and multimedia source, but its current layout must not be copied.
- LinkedIn PDF and CV will be used to verify professional information.
- Architectural Design and Bio-Design are two connected dimensions of the same practice.
- Use structured content instead of hardcoded professional information.

## Architecture and implementation

- Do not add Supabase, authentication, a database, or a CMS.
- Do not build advanced animations before completing the content audit and information architecture.
- Do not sacrifice mobile performance for cinematic effects.
- Videos must be optimized and lazy-loaded.
- Twinmotion panoramas must load only after user interaction.
- Run validation after substantial implementation.
