# Alessandro Bobbio Russian — Personal Portfolio

This repository is the foundation for the definitive personal portfolio of **Alessandro Bobbio Russian**, an Architectural Designer working in luxury interiors.

## Portfolio scope

The future website will:

- present Alessandro's architectural design practice and selected luxury-interior work;
- document his professional ecosystem involving **Febal Casa, Grupo TJC, Bontempi, Colombini Group, and Sola Cocinas**, using only relationships verified by the repository's source material;
- present his Bio-Design work with **Urban Ponics** as a connected dimension of the same practice;
- integrate renders, architectural videos, Twinmotion Panorama Sets, technical drawings, project processes, origins, education, and an interactive CV.

The primary concept guiding the portfolio is **“From Bit to Matter”**: the movement from ideas and digital processes into designed, built, and living material outcomes.

## Planned production stack

The production website will use:

- Next.js
- TypeScript
- Tailwind CSS
- Motion

The application and its dependencies are intentionally not included in this foundation phase.

## Source material

Professional claims must be verified before publication. Repository files are the primary source of truth, supported by these existing sources:
